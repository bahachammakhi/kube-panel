# Changelog

## 0.1.1 — 2026-11-11

- Add the actual log inspector preview as the plugin cover so the directory can show it instead of generic artwork.
- Expand the listing description with the log tools, events, YAML, connection workflow, and read-only behavior.
- No changes to runtime behavior or requested access.

## 0.1.0 — 2026-11-10

Initial release.

- Compact Kubernetes pod and deployment browser with context and namespace selection.
- Log inspector with search, severity filters, structured JSON fields, optional polling, follow, wrap, and copy.
- YAML highlighting and event cards with counts and timestamps.
- Read-only k9s launcher that reveals its terminal in Orca.
- Workspace-specific preferences, bounded read requests, and no kubeconfig context changes.
